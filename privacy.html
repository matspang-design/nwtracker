NWtracker

Privacy Policy

Last updated 12 October 2026 Version 1.0

The short version

NWtracker is a personal budgeting program that one private individual runs on their own computer, for their own household. It has no servers, no accounts for other people, and no analytics. Your financial data is written to a file on your own machine and is never sent anywhere else.

The only data that leaves the computer is the request the program makes to a bank or exchange you have chosen to connect, and that access is read-only.

1Who is responsible

NWtracker is not a company and not a public service. It is a program written and operated by one private individual (the operator) for their own household's use. The operator is both the controller of the data and, together with members of their household, its only subject.

No account is offered to anyone else, and no one outside the operator's household can use the program or see its data.

2What the program reads

Only where the operator explicitly connects a source:

  • Account balances and booked transactions from a bank account, through an authorised open-banking provider.
  • Balances and holdings from a crypto exchange, through a read-only API key.
  • Files the operator exports and places in the program's folder: bank statement exports, broker statements, payroll documents.

Access to a bank is limited to balances and transactions. The program never initiates a payment or a transfer and does not request permission to do so.

3Where the data is kept

In a database file on the operator's own computer. The dashboard is served only to 127.0.0.1 — the computer itself — unless the operator deliberately turns on access from their own home network, which is protected by a PIN.

There is no cloud component, no hosted backend and no remote backup. Nothing is uploaded, because there is nowhere for it to be uploaded to.

4What is deliberately not stored

Some information is refused at the point of entry, so no later part of the program can reintroduce it:

  • Account numbers are stored as a one-way hash plus a masked form such as DE89…5136. The full number is never written to the database.
  • Payroll documents are read for money only — gross, net, amount paid. Tax identifiers, social-security numbers, dates of birth, health-insurer names and religious affiliation are not extracted, even though they appear on the document.
  • Email addresses and long reference numbers are stripped out of transaction descriptions before they are stored.

5Credentials

An API key, its secret, and the private key used to sign open-banking requests stay on the operator's computer, as environment variables and as a file on disk. They are never written into the program's configuration, its database, its logs, or any error message, and they are never transmitted anywhere except to the institution they authenticate against.

6Who the data is shared with

Nobody. The data is not sold, not shared, not used for advertising, and not used to train anything. There are no third-party analytics, no tracking, no crash reporting and no telemetry of any kind.

The open-banking provider that carries a bank connection necessarily handles that account's data in transit under its own privacy policy, as the licensed party in that arrangement. No other third party is involved.

7How long it is kept

Until the operator deletes it. Deleting the database file removes everything the program has stored; the file can be rebuilt at any time from the original exports.

8Withdrawing access

A bank consent can be withdrawn at any time, either in the open-banking provider's control panel or directly in the bank's own online banking, under third-party access. An exchange API key can be deleted in the exchange's own settings. Either action takes effect immediately and independently of this program.

9Your rights

Because the operator and the data subject are the same person, the rights under the GDPR — access, rectification, erasure, portability, objection — are exercised directly: the data sits in a file the operator owns, in an open format, on their own machine.

10Contact

Questions about this policy or about the data the program holds go to the operator, at the data-protection address given when the application was registered: matspang@gmail.com

11Changes

If the program's behaviour changes in a way that affects any of the above, this page is updated and the date at the top changes with it.

NWtracker is a private, non-commercial program. It is not a financial service, it does not give financial advice, and it holds no money.
